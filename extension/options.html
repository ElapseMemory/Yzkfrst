Safe Page Translator 设置

配置多个翻译模板（如自定义 LLM、Google 翻译、百度翻译），根据当前需求切换使用。所有配置仅保存在浏览器的同步存储中。

全局默认语言

用于弹窗快速翻译及整页翻译的初始语言，可随时在弹窗修改目标语言。

模板选择与管理

可以为不同翻译供应商或提示词创建独立模板，弹窗与整页翻译会使用选中的模板。删除模板不会影响其他模板的设置。

Google 翻译 API

语言识别

Google 翻译自带语言识别接口，可选择是否启用自动检测。

百度翻译 API

语言识别

百度翻译支持语言检测接口，需使用同一套凭证。

整页翻译行为

设置会保存在浏览器的同步存储中，不会上传到其他地方。
